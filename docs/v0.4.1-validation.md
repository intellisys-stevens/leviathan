## Tooltip profile

The same production fixture was used before and after: 13 plotted series,
600 source samples, 0.5-second SSE updates, and 120 pointer moves. Environment:
macOS Darwin 25.6 arm64, Headless Chrome 151.0.7922.34, 1280×900, DPR 1,
10 reported hardware threads. Timing runs from the mouse handler to the first
animation frame after a tooltip mutation, not a hardware presentation timestamp.

| Measurement | Baseline dark runs | Final dark | Final light |
| --- | --- | --- | --- |
| p95 response | 8.7 / 8.8ms | 8.5ms | 9.0ms |
| Tooltip rectangle reads | 152 / 153 | 12 | 12 |
| Invisible tooltip frames | 0 / 0 | 0 | 0 |
| Longest response | 129.2 / 10.1ms | 9.8ms | 127.3ms |

Tooltip measurements fell about 92%. The p95 target of 50ms was met, but a
live-render tail spike remains; this is not a claim that all chart lag is gone.
Sampling, source averages, retained history, and missing-data gaps are unchanged.
Fourteen production browser cases passed; six were intentionally excluded for
their viewport. Dense profiling is opt-in because React development profiling
itself failed under the dense fixture. To repeat, build and start a production
preview on port 4173, then run:

```bash
LEVIATHAN_PROFILE_TOOLTIPS=1 npm run test:e2e -- tooltip-v041.spec.ts --workers=1
```

## Capacity limits

An eight-GPU fixture with overlapping MIG placements computes alternatives in
approximately 5.45ms and allocates 3.84MB per evaluation on the measured Mac.
A compiled test process peaked near 37.2MiB RSS. These fixture results do not
bound real cluster informer memory or allocator complexity. Evaluation has a
two-second deadline and explicit inventory limits; unsupported or incomplete
inputs yield unknown counts. This turn did not deploy the bridge or verify
allocation against a live Kubernetes cluster.

The standard chart enables read-only cluster-wide reservations by default.
See [Kubernetes capacity configuration](kubernetes-attribution.md#live-gpu-capacity)
for opt-out, installation, and rollback behavior. The GPU profile counts are
alternatives and do not reserve resources or guarantee whole-workload admission.
